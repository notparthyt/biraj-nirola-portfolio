# Biraj Nirola | Harshira Visuals

Static portfolio website for mobile thumbnail designer Biraj Nirola.

## Live site

https://notparthyt.github.io/biraj-nirola-portfolio/

## Deployment

The site is deployed to GitHub Pages by `.github/workflows/pages.yml` whenever changes are pushed to `main`. The workflow uploads the static site directly; no build tools or package installation are required.

## Search visibility

The site includes a canonical URL, social sharing metadata, Person and WebSite structured data, `robots.txt`, and an XML sitemap. Search engines may take time to crawl and index a newly published site.
